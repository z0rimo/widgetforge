# WF2002: Widget receiver lacks APPWIDGET_UPDATE intent-filter

**Symptom:** Widget is missing from the picker or never receives updates.

**Cause:** A `<receiver>` with `android.appwidget.provider` meta-data has no intent-filter containing `android.appwidget.action.APPWIDGET_UPDATE`.

**Fix:** Add `<intent-filter><action android:name="android.appwidget.action.APPWIDGET_UPDATE"/></intent-filter>` to the receiver.
