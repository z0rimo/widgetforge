# WF5008: Widget extension deployment target is below iOS 14

**Symptom:** The widget extension does not compile or cannot be built for that deployment target.

**Cause:** `IPHONEOS_DEPLOYMENT_TARGET` of the widget extension is lower than 14.0, the first iOS version with WidgetKit.

**Detection:** Resolved per build configuration (target setting over target `.xcconfig` over project setting over project `.xcconfig`); a Release-only low value is reported with its configuration name. Unresolvable values produce a note. The app target's own deployment target is not judged.

**Basis and limits:** WidgetKit's availability (iOS 14.0+) is not stated on the Apple pages that could be read; the validation sample (deployment target 14.0) built and ran on an iOS 26.5 simulator, but a target below 14 was not built, so this rule's basis is still not verified with Xcode.

**Fix:** Set the extension's `IPHONEOS_DEPLOYMENT_TARGET` to 14.0 or higher (Flutter's guide also asks that the deployment targets of the app and the extension be set consciously).

Fixtures: `fixtures/err_ios_deployment_target_below_14`, `fixtures/err_ios_release_only_deployment_target`.

**Evidence level:** static analysis of `ios/*.xcodeproj/project.pbxproj`, plists and Swift sources on Linux. Additionally checked on a Flutter project built with Xcode 26.6 on macOS: no finding on the clean project, and this finding when the condition was introduced into the project files, with the report clean again after reverting ([iOS validation record](../ios-validation.md)). The broken project was not built; the symptom was not reproduced.
