# WF6002: Widget receiver without android.appwidget.provider meta-data in the built APK

**Symptom:** The widget does not appear in the launcher picker or shows "Problem loading widget"; the launcher cannot find the widget configuration.

**Cause and detection:** A `<receiver>` in the final manifest has the `android.appwidget.action.APPWIDGET_UPDATE` action but no `<meta-data android:name="android.appwidget.provider">`.

**Basis and limits:** Verified on a real Flutter debug APK built with Gradle: Gradle builds such an APK without complaint, and `apkanalyzer manifest print` shows the receiver without meta-data. Produced only by `widgetforge verify <file>`; `doctor` never emits it. Analysis is static and read-only: no install, no emulator or device run.

**Fix:** Add the meta-data pointing to an `@xml` AppWidgetProviderInfo file and rebuild. Source counterpart: [WF2003](WF2003.md).

Fixtures: `test/artifacts/real_debug_widget_missing_meta.apk` (trimmed real build), synthetic archives in `test/artifact_test.dart`.

**Evidence level:** structure of a built APK read in pure Dart (ZIP, binary XML, resources.arsc); compared with `apkanalyzer` and `aapt2` on real builds on Linux.
