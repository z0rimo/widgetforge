# WF3001: Widget provider XML not found / invalid

**Symptom:** Build or runtime failure resolving `@xml/<name>`, or the widget cannot be added.

**Cause:** The `android.appwidget.provider` meta-data points to an `@xml/...` resource that does not exist in `res/xml*/`, is not an `@xml` reference, is not well-formed, or its root is not `<appwidget-provider>`.

**Fix:** Create `android/app/src/main/res/xml/<name>.xml` with an `<appwidget-provider>` root, or correct `android:resource`.
