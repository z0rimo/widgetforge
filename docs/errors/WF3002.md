# WF3002: appwidget-provider lacks android:initialLayout

**Symptom:** Widget cannot be added or shows a loading error.

**Cause:** The provider XML has no `android:initialLayout`.

**Fix:** Add `android:initialLayout="@layout/<widget_layout>"` and create the layout (restricted to RemoteViews-safe views, see WF1001).
