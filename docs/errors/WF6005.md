# WF6005: initialLayout referenced by the built APK is missing

**Symptom:** The launcher cannot inflate the widget layout.

**Cause and detection:** `android:initialLayout` is resolved through `resources.arsc`; no layout file for that id exists in the archive.

**Basis and limits:** Layout contents (RemoteViews class support) are not examined in the APK; use `doctor` for [WF1001](WF1001.md). Produced only by `widgetforge verify <file>`; `doctor` never emits it. Analysis is static and read-only: no install, no emulator or device run.

**Fix:** Make sure the layout exists and survives resource shrinking, then rebuild. Source counterpart: [WF3003](WF3003.md).

Fixtures: synthetic archives in `test/artifact_test.dart`.

**Evidence level:** structure of a built APK read in pure Dart (ZIP, binary XML, resources.arsc); compared with `apkanalyzer` and `aapt2` on real builds on Linux.
