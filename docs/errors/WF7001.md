# WF7001: Info.plist in the IPA is missing, unreadable or lacks a required key

**Symptom:** The app or extension may be rejected at install or never loaded.

**Cause and detection:** The app or an embedded `.appex` has no `Info.plist`, the plist cannot be parsed (XML and binary `bplist00` are both read), the app has no `CFBundleIdentifier`, or an extension has no `NSExtension > NSExtensionPointIdentifier`.

**Basis and limits:** An IPA fixture here is a synthetic archive, not an Apple build. Not verified with Xcode. Produced only by `widgettriage verify <file>`; `doctor` never emits it. Analysis is static and read-only: no Xcode build, simulator or device run was performed.

**Fix:** Check the target Info.plist and build settings in Xcode and re-export. Source counterpart: [WF5003](WF5003.md).

Fixtures: synthetic archives in `test/artifact_test.dart`.

**Evidence level:** structure of an IPA read in pure Dart (ZIP, XML/binary plist); no real Apple build was available, macOS/Xcode NOT RUN.
