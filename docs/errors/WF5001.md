# WF5001: Widget extension is not embedded in an app target

**Symptom:** The project contains a WidgetKit extension target, but the built app does not contain the widget (it never appears in the widget gallery). WidgetTriage did not observe this on a device or simulator.

**Cause:** The extension's product (`<Name>.appex`) is not in an "Embed Foundation Extensions" (older Xcode: "Embed App Extensions") copy-files build phase of the app target. An extension that is not embedded is not part of the app bundle.

**Detection:** The `.xcodeproj` is parsed as a property list (not by text search). Widget extension targets are app-extension targets whose Swift sources import `WidgetKit` or whose Info.plist declares `com.apple.widgetkit-extension`. The finding appears only when an app target exists and no copy-files phase with destination 13 (PlugIns / Foundation Extensions) of any app target references the extension's product. Embedding by other means (for example a script phase) is not recognized.

**Fix:** In Xcode, select the app target > Build Phases > Embed Foundation Extensions, add the `.appex`, and keep that phase above "Run Script" / "Thin Binary" (the order the Flutter app-extension guide describes).

Fixture: `fixtures/err_ios_widget_not_embedded`; not reported: `fixtures/ok_ios_widget_basic`, `fixtures/ok_ios_synchronized_folder_group`.

**Evidence level:** static analysis of `ios/*.xcodeproj/project.pbxproj`, plists and Swift sources on Linux. Additionally checked on a Flutter project built with Xcode 26.6 on macOS: no finding on the clean project, and this finding when the condition was introduced into the project files, with the report clean again after reverting ([iOS validation record](../ios-validation.md)). The broken project was not built; the missing-widget symptom was not reproduced.
