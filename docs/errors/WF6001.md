# WF6001: Widget receiver without android:exported in the built APK

**Symptom:** The APK cannot be installed on Android 12+ (targetSdkVersion 31 or higher) or the component is rejected.

**Cause and detection:** The final binary `AndroidManifest.xml` has a `<receiver>` with an AppWidget intent filter, no `android:exported` attribute, and `uses-sdk targetSdkVersion` >= 31. If targetSdkVersion cannot be read, or `exported` is not a boolean literal, a note is emitted instead.

**Basis and limits:** The source manifest rule WF2004 judges `src/main` manifests; this rule judges the merged result in the APK. Gradle normally stops the build before such an APK exists, so this mainly catches hand-edited or third-party APKs. Produced only by `widgettriage verify <file>`; `doctor` never emits it. Analysis is static and read-only: no install, no emulator or device run.

**Fix:** Add `android:exported="true"` to the widget receiver in the source manifest and rebuild. Source counterpart: [WF2004](WF2004.md).

Fixtures: synthetic archives in `test/artifact_test.dart`.

**Evidence level:** structure of a built APK read in pure Dart (ZIP, binary XML, resources.arsc); compared with `apkanalyzer` and `aapt2` on real builds on Linux.
