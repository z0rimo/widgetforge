# WF7004: Widget extension MinimumOSVersion is below iOS 14 (IPA)

**Severity: warning (Experimental).** Does not change the exit code. Do not change deployment targets on this finding alone.

**Symptom:** The extension declares support for an OS version older than the one in which WidgetKit was introduced.

**Cause and detection:** For an embedded extension whose extension point is `com.apple.widgetkit-extension`, the major version of `MinimumOSVersion` in its `Info.plist` is below 14. Source counterpart: [WF5008](WF5008.md). Produced only by `widgettriage verify <file>`. A missing `MinimumOSVersion` yields a note, not a finding.

**Basis (see [verify-contract](../verify-contract.md)):**
- A. Apple's WidgetKit documentation data lists iOS `introducedAt: 14.0`.
- D. Not stated on any readable page and not tested: that a lower `MinimumOSVersion` actually makes a build, validation or install fail, and how `MinimumOSVersion` in an IPA relates to the target's deployment target in unusual setups (weak linking, multiple targets).

**Fix:** If a real build confirms a problem, set the extension's deployment target to 14.0 or higher and rebuild. Otherwise leave it.

**Evidence level:** structure of an IPA read in pure Dart; no real Apple build was available, macOS/Xcode NOT RUN.
