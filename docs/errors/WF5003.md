# WF5003: Widget extension Info.plist is missing or invalid

**Symptom:** The build fails or the extension has no `NSExtension` declaration.

**Cause:** The widget extension has no `INFOPLIST_FILE` (and does not generate one), or the file does not exist, or it is not a valid XML property list.

**Detection:** `INFOPLIST_FILE` is resolved per build configuration (Debug/Release can differ). With `GENERATE_INFOPLIST_FILE = YES` and no file, only a note is produced because `NSExtension` cannot be checked.

**Fix:** Create the Info.plist, correct `INFOPLIST_FILE`, or fix the XML syntax.

Fixture: `fixtures/err_ios_info_plist_file_missing`.

**Evidence level:** static analysis of `ios/*.xcodeproj/project.pbxproj`, plists and Swift sources on Linux. Additionally checked on a Flutter project built with Xcode 26.6 on macOS: no finding on the clean project, and this finding when the condition was introduced into the project files, with the report clean again after reverting ([iOS validation record](../ios-validation.md)). Checked in three variants of the missing/invalid Info.plist case; the broken projects were not built and the symptom was not reproduced.

**Sources:**
