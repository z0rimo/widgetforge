# WF6004: Provider XML in the built APK has no android:initialLayout

**Symptom:** The widget has no layout to show before its first update and cannot be added correctly.

**Cause and detection:** The binary AppWidgetProviderInfo XML (`appwidget-provider`) has no `initialLayout` attribute. Source counterpart: [WF3002](WF3002.md).

**Basis and limits:** Verified on a real Flutter debug APK built with Gradle (Gradle accepts a provider XML without initialLayout). Produced only by `widgetforge verify <file>`; `doctor` never emits it. Analysis is static and read-only: no install, no emulator or device run.

**Fix:** Add `android:initialLayout="@layout/..."` and rebuild.

Fixtures: `test/artifacts/real_debug_widget_missing_meta.apk` (trimmed real build), synthetic archives in `test/artifact_test.dart`.

**Evidence level:** structure of a built APK read in pure Dart (ZIP, binary XML, resources.arsc); compared with `apkanalyzer` and `aapt2` on real builds on Linux.
