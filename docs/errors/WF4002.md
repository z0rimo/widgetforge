# WF4002: Dart entrypoint lacks @pragma('vm:entry-point')

**Symptom:** Works in debug, fails in release/profile: the secondary entrypoint cannot be found.

**Cause:** The function is only referenced by name from native code, so the AOT tree shaker drops it unless it is annotated with `@pragma('vm:entry-point')` (the FlutterActivity documentation requires the annotation for non-`main` entrypoints). Observed once: in a release build of an isolated sample on Flutter 3.32.0, an annotated function and its string were present in `libapp.so` and an unannotated one was absent. The exact runtime error message was not reproduced.

**Detection:** The entrypoint function is found as a top-level declaration (see WF4001) and its own annotations are read: `@pragma('vm:entry-point')` and `@pragma('vm:entry-point', true)` count; `false` does not. The annotation may be on the same line, or separated from the declaration by comments or blank lines; line distance plays no role. If several libraries declare a function of that name, one annotated declaration is enough. Each declaration is reported once, however many activities use it.

**Fix:** Put `@pragma('vm:entry-point')` on the function declaration.
