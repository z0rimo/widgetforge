# WF4003: FlutterActivity subclass is not registered in the manifest

**Symptom:** `ActivityNotFoundException` when starting the activity (the usual Android behavior for an unresolvable explicit intent; not reproduced by WidgetForge).

**Cause:** A concrete class that extends `FlutterActivity`/`FlutterFragmentActivity` (directly or through project classes) has no `<activity>`/`<activity-alias android:targetActivity>` entry in any `android/app/src/*/AndroidManifest.xml`.

**Detection:** Same class reader and name resolution as WF2001: comments, strings and abstract classes are ignored, relative names use the module `namespace`, an unresolvable supertype means "unknown" (no report), and the merged manifest is not computed.

**Fix:** Add `<activity android:name=".MyActivity" android:exported="false" android:theme="@style/LaunchTheme" android:hardwareAccelerated="true" android:windowSoftInputMode="adjustResize"/>` (plus the `configChanges` your MainActivity uses).
