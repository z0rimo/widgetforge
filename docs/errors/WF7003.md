# WF7003: Widget extension executable is missing from the IPA

**Symptom:** The extension cannot load.

**Cause and detection:** The widget extension `Info.plist` names a `CFBundleExecutable` that is not present in the `.appex` directory of the archive.

**Basis and limits:** Only presence is checked; the Mach-O file is not read. Produced only by `widgettriage verify <file>`; `doctor` never emits it. Analysis is static and read-only: no Xcode build, simulator or device run was performed.

**Fix:** Rebuild and re-export the IPA.

Fixtures: synthetic archives in `test/artifact_test.dart`.

**Evidence level:** structure of an IPA read in pure Dart (ZIP, XML/binary plist); no real Apple build was available, macOS/Xcode NOT RUN.
