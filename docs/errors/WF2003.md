# WF2003: Widget receiver lacks android.appwidget.provider meta-data

**Symptom:** Widget is not selectable; Android cannot read size or layout info.

**Cause:** A `<receiver>` declares `APPWIDGET_UPDATE` but has no `<meta-data android:name="android.appwidget.provider" .../>`.

**Fix:** Add the meta-data pointing at `@xml/<provider_info>` and create that XML (see WF3001).
