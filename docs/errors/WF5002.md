# WF5002: Widget extension Info.plist does not declare the WidgetKit extension point

**Symptom:** The extension builds but is not recognized as a widget extension.

**Cause:** `NSExtension` > `NSExtensionPointIdentifier` in the extension's Info.plist is missing or is not `com.apple.widgetkit-extension`.

**Detection:** The Info.plist named by `INFOPLIST_FILE` (build settings and referenced `.xcconfig` files are resolved; unresolvable values produce a note) is read as an XML property list. Binary plists are not read (note). Targets are judged only when they are widget extensions (see WF5001).

**Basis and limits:** Apple's `NSExtensionPointIdentifier` page lists `com.apple.widgetkit-extension` among its possible values (read via the page's JSON data form; the HTML page returned only its title). The page attaches no description to any value, so that this value is the one used by widget extensions rests on Xcode's Widget Extension template and the value's name, and was not verified against Xcode's own template. In the validation sample, an extension declaring this value built, was registered by `pluginkit` with that extension point and showed its widget in an iOS 26.5 simulator ([iOS validation record](../ios-validation.md)); a different value was not built.

**Fix:** Set `NSExtension` > `NSExtensionPointIdentifier` to `com.apple.widgetkit-extension`.

The broken project was not built; the symptom was not reproduced.
