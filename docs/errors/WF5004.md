# WF5004: Widget extension bundle identifier is not prefixed with the app bundle identifier

**Symptom:** Archiving or validating the app fails because the embedded extension's bundle identifier does not belong to the app.

**Cause:** An app extension's `PRODUCT_BUNDLE_IDENTIFIER` must start with the containing app's bundle identifier plus a dot (for example app `com.example.demo`, extension `com.example.demo.DemoWidget`).

**Detection:** Compared per build configuration after resolving build settings and `.xcconfig` variables. If either value depends on something WidgetTriage cannot resolve, only a note is produced.

**Basis and limits:** This is Apple's app-extension rule; the Apple and Flutter pages that could be read do not state it, and it was not verified with Xcode. The validation sample used a conforming prefix, built and installed; a non-conforming prefix was not built.

**Fix:** Use `<app bundle id>.<suffix>` for the extension.
