# WF3003: Widget layout resource not found

**Symptom:** Resource linking error (`resource layout/xxx not found`) or broken widget.

**Cause:** `android:initialLayout` or `android:previewLayout` in the provider XML does not resolve to a file in any `res/layout*/` directory.

**Fix:** Create `res/layout/<name>.xml` or correct the reference.
